# ODRL-Evaluator-Demo

Checkout the live demo [here](https://woutslabbinck.github.io/ODRL-Evaluator-Demo/).

There are two other versions out:
- an ODRL3 version, which accompanies the [FORCE paper](https://ceur-ws.org/Vol-4064/NXDG25-paper6.pdf)
  - https://w3id.org/force/demo/odrl3proposal
- A version with 4 scenarios created for the final [SolidLab](https://solidlab.be/) Plenary (19 January 2026)
  - https://woutslabbinck.github.io/ODRL-Evaluator-Demo/solidlab.html


## Develop locally

The bulk of the code is in the [index.html](./docs/index.html) file.
```sh
npm start
```
